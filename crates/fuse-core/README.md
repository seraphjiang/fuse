# fuse-core

Core types, traits, and configuration for the [Fuse](https://github.com/seraphjiang/fuse) federated query engine.

This crate defines the `FederatedConnector` trait, `ConnectorFactory`, query expression types, and configuration parsing. Connector authors should use [`fuse-connector-sdk`](https://crates.io/crates/fuse-connector-sdk) instead of depending on this crate directly.
