## Comparison vs v1.1.0

| Benchmark | v1.1.0 | v2.0 | Delta | Notes |
|-----------|--------|------|-------|-------|
| PPL parse (simple) | 411 ns | 830 ns | +102% | More features in parser |
| PPL parse (complex) | 1.22 µs | 7.77 µs | +537% | Lookup/enrichment support added |
| hash_join 1K | 375 µs | 1.34 ms | +257% | Build-side selection overhead |
| hash_join 10K | 4.54 ms | 19.0 ms | +318% | Same |
| dedup 10K | 498 ns | 944 ns | +90% | — |
| sort_batches 40K | 160 µs | 274 µs | +71% | — |

Note: Regressions are expected — v2.0 added significant functionality (cost-based join planning,
build-side selection, PPL lookup, query compilation). Absolute numbers remain well within
acceptable bounds for a federated query engine where network RTT dominates (1-100ms per connector).
