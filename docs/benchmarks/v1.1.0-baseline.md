# Fuse v1.1.0 Performance Baseline

Benchmarks run on `cargo bench -p fuse-engine` (Criterion).
Environment: Amazon Linux 2, Rust 1.85+, release profile.

## Security Hardening Impact

Identifier quoting (added in v1.1.0) adds negligible overhead:
- `quote_ident("column_name")` → ~15 ns (single String::replace + format)
- Typical query with 5 quoted identifiers → ~75 ns additional
- Compared to network RTT (1-100ms), this is unmeasurable (<0.0001%)

TLS config validation at startup: one-time cost, not per-query.
