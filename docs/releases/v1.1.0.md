# Fuse v1.1.0 Release Notes

**Release Date:** 2026-04-11
**Sprints:** 12–15 (100+ items shipped)
**Tests:** 719 core unit tests + 257 integration tests, 0 failures

## Headline Features

### 22 Connectors
Query any datasource with SQL or PPL. New in v1.1: Kafka, Athena, Timestream, Snowflake, BigQuery, Cassandra, DuckDB, Arrow Flight (zero-copy streaming).

### Fuse-to-Fuse Federation
Chain Fuse instances for multi-region or tiered deployments. Cost-based routing selects the lowest-latency healthy instance. Cross-cluster JOINs work transparently.

### Complete Write Path
- CREATE TABLE AS SELECT (CTAS)
- INSERT INTO ... SELECT
- BEGIN/COMMIT/ROLLBACK transactions
- Write connectors: Postgres, DuckDB, S3 (Parquet output)

### AI-Powered Query Experience
- Natural language to SQL (LLM-powered, Bedrock/OpenAI backends)
- Query optimization advisor (7 rules with severity + suggested rewrites)
- Context-aware autocomplete in playground

### Async Query API
Submit long-running queries and poll for results. Job lifecycle tracking (Pending→Running→Completed/Failed/Cancelled) with TTL eviction.

### Distributed Tracing
W3C Trace Context propagation + OpenTelemetry OTLP export. Trace queries across federated Fuse instances and connectors.

## Security

- TLS/mTLS for all connector connections (rustls)
- Datasource-level RBAC (Read/Write/Admin permissions)
- Secret management via AWS Secrets Manager (secret:// URIs)
- Tenant isolation derived from authenticated identity (not client params)
- WASM plugin sandboxing with fuel metering + input size caps
- Identifier quoting across all 9 SQL/CQL pushdown connectors
- Error message sanitization — no internal details leaked
- Structured error codes (FUSE-1000 through FUSE-7001)

## Performance

- Arrow Flight zero-copy streaming (no JSON serialization)
- Adaptive parallelism per datasource
- Per-datasource rate limiting (tokio semaphores)
- Query plan caching with normalization + hit rate metrics
- Adaptive query timeout (per-datasource p95-based)
- Result size limits (configurable max_result_bytes)
- Graceful shutdown with query draining

## Ecosystem

- **Go SDK** — stdlib-only, full API surface
- **Python SDK** — pandas DataFrame, saved queries, NDJSON streaming
- **Jupyter magic** — %fuse / %%fuse with auto DataFrame
- **Grafana plugin** — template variables, multi-line editor
- **VS Code extension** — inline results, syntax highlighting
- **OpenSearch Dashboards plugin** — synced with v1.1 API

## Observability

- EXPLAIN ANALYZE with per-node execution stats
- Flame graph + DAG visualization in playground
- Health dashboard with per-connector timeline
- Audit log export (NDJSON, incremental, drain)
- Alert monitor with webhook notifications + CRUD API
- Query cost badge in playground

## Infrastructure

- Stateless server mode (Redis-backed shared state)
- CORS configuration (fuse.toml)
- Configuration validation on startup
- Retry with exponential backoff for connectors
- Federation health aggregation
- E2E integration test suite (18 scenarios)
- Performance benchmark script

## Breaking Changes

- `FuseError::Connector` and `FuseError::Config` are now struct variants with `code` and `msg` fields. Use `FuseError::connector(msg)` / `FuseError::config(msg)` convenience constructors.
- Tenant ID is now derived from `AuthIdentity`, not from request params.
