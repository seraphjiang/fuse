Example Queries (click to load)

PPL Search errors across clusters source = cluster_a.application_logs, cluster_b.application_logs | where status >= 500 | head 20
SQL Error count by service SELECT service, count(*) as errors FROM cluster_a.application_logs WHERE status >= 500 GROUP BY service ORDER BY errors DESC
SQL Cross-cluster trace lookup SELECT * FROM cluster_a.application_logs WHERE trace_id = 'trace-001'
PPL Aggregate by status code source = cluster_a.application_logs | stats count() by status | sort - count()
SQL Federated union SELECT service, status, message FROM cluster_a.application_logs UNION ALL SELECT service, status, message FROM cluster_b.application_logs LIMIT 20
