Getting Started

Fuse is a federated query engine that lets you query across multiple OpenSearch clusters and S3 data from a single SQL or PPL query.

Dashboards → Fuse Server → DataFusion Planner
                              ↓       ↓       ↓
                           OS(a)   OS(b)   S3 O11y
                              ↓
                         Result Merger

Write a query above, click ▶ Run, or try 🎲 Feeling Lucky.

SQL Reference

Tables use datasource.table syntax.

SQLSELECT / WHERE / ORDER BY / LIMIT
SQLGROUP BY + aggregations
SQLJOIN across datasources

Functions: COUNT, SUM, AVG, MIN, MAX

PPL Reference

Syntax: source = ds.table | command | command

PPLwhere + fields + head
PPLstats + sort
PPLdedup

Commands: where, stats (by), sort (- desc), head, fields, dedup, eval

Multi-source: source = a.table, b.table | ...

Data Provenance

Cross-datasource queries add a _datasource column showing which source each row came from. The provenance bar below results shows per-datasource row counts and latency.

EXPLAIN / ANALYZE

Explain shows the execution plan without running the query. Analyze (checkbox) runs the query and shows actual row counts and timing per node.

Pushdown badges on RemoteScan nodes show which operations were pushed to the connector (filter, projection, limit).

Color coding: green <50ms, yellow <200ms, red >200ms

Troubleshooting

"datasource not found" — Check datasource name matches cluster_a, cluster_b, or s3_o11y
"empty results" — Verify the index has data. Try SELECT * FROM ds.table LIMIT 1
"timeout" — Reduce LIMIT, check connector health via GET /api/fuse/health
"degraded health" — A connector is slow or unreachable. Check config and network

Query Endpoints

MethodPathDescription
POST/api/fuse/queryExecute query. Body: {"query":"...","format":"sql|ppl","analyze":false}
POST/api/fuse/query/explainShow execution plan

  -H 'Content-Type: application/json' \
